# CI/CD Learning Project

Angular SPA + ASP.NET Core Web API, built as a hands-on vehicle for learning
the full CI/CD lifecycle: Git workflow, CI pipeline, Docker, container
registry, and deployment across dev/staging/production environments on Azure.

## Structure

- `frontend/` — Angular single-page app
- `backend/` — ASP.NET Core minimal Web API (`/api/hello`, `/health`)

This README will grow as each phase of the project is completed.
